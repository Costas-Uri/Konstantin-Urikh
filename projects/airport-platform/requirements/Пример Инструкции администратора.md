# 1. Общие положения

Статья описывает процесс создания / редактирования представления View.

# 2. Определения

1. View - представление (витрина) таблицы БД.  
Отличие от таблицы БД в том, что в представление View администратор добавляет не все столбцы таблицы, а только те, которые представляют интерес для Пользователей Контекста.

2. Object - объект (таблица) БД, для которого создается представление View.

3. Pre-Filter - предварительная фильтрация записей. В представлении View будут отображены только те записи, которые соответствуют условиям фильтрации.

4. Column - колонка, добавляемая в представление View. В колонке будут отображаться данные из объекта Object.

5. Action - действие, запускаемое по какому-то событию Event. Действие может открывать форму для редактирования View, запускать команду, отображать контекстное меню и т.д. 

6. ЛКМ - левая кнопка мыши.

# 3. Предусловие

Администратор зашел в один из Контекстов системы с правами Администратора.
