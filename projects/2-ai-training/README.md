# Учебный проект: ИИ-Акселератор для аналитиков

**Курс:** ИИ-Акселератор для аналитиков  
**Результат:** 🥉 3-е место из 60 участников  
**Роль:** Слушатель, обучающийся  
**Цель:** Освоение инструментов ИИ для решения задач системного и бизнес-аналитика

---

## О проекте

Курс был посвящён использованию искусственного интеллекта в работе аналитика. В рамках обучения мы работали над сквозным проектом — **системой обслуживания отелей L’auberge GA**.

Я прошёл полный цикл: от сбора требований до создания MVP, используя ИИ для генерации артефактов, проектирования БД, моделирования процессов и разработки прототипов.

---

## 🔧 Что я освоил и применил

### 📋 Анализ и проектирование
- Сбор и документирование бизнес-требований (БТ), функциональных (ФТ) и нефункциональных (НФТ) требований
- Написание User Stories и Use Cases с помощью ИИ
- Моделирование бизнес-процессов в **BPMN 2.0** и UML-диаграмм (Sequence, ER)
- Проектирование логической и физической модели БД (SQLite/PostgreSQL)
- Разработка REST API-документации в формате OpenAPI (Swagger)
- Архитектурное моделирование в нотации C4

### 🖥️ Прототипирование и разработка
- Создание UI/UX-прототипов 
- Проектирование flow-сценариев (многошаговые процессы)
- Разработка MVP-приложения на Vercel
- Написание Python-скриптов в Google Colab для работы с LLM

### 🤖 ИИ-инструменты и автоматизация
- Работа с локальными LLM (настройка параметров: температура, top_p и др.)
- Разработка AI-агентов в **n8n** (автоматизация обработки данных)
- Тестирование API LLM (OpenAI, YandexGPT) через Postman
- Создание RAG-пайплайна и Fine-Tuning моделей
- Использование ИИ для генерации диаграмм, кода и документации
