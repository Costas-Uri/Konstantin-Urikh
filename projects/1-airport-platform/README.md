# Платформа управления службами аэропорта

**Статус:** 🔄 В работе  
**Роль:** Ведущий аналитик  
**Стек:** BPMN, UML, Figma, Postman, DBeaver, Jira, Confluence

---

## О проекте
Автоматизация рутинных операций по обслуживанию воздушных судов в аэропортах. Импортозамещение — переход на собственное ПО вместо западных решений. Проект находится в активной фазе разработки.

## Мои задачи
- Сбор и уточнение требований у заказчика
- Моделирование бизнес-процессов (BPMN 2.0)
- Описание сценариев использования (Use Case)
- Прототипирование пользовательских интерфейсов (Figma)
- Документирование и постановка задач разработчикам
- Планирование работы аналитиков и оценка трудозатрат
- Менторинг младшего аналитика
- Приёмка функционала совместно с командой тестирования
- Анализ данных заказчика с помощью ИИ (выявление узких мест)
