### 🔹 Проект 2: ИИ-Акселератор для аналитиков, обучение

**Статус:** ✅ Завершён  
**Результат:** 🥉 3-е место из 60 участников  
**Роль:** Слушатель, обучающийся  

**Задача:** Освоить современные ИИ-инструменты и применить их для автоматизации задач системного и бизнес-аналитика на примере сквозного проекта — системы бронирования отелей

**Что сделано:**
- Собраны и документированы **бизнес-, функциональные и нефункциональные требования** с помощью ИИ
- Разработаны **BPMN-диаграммы** процесса регистрации гостя и **ER-диаграмма** базы данных отеля
- Написаны промпты для генерации артефактов (**Use Cases, User Stories, SQL-скрипты, API-документация**)
- Создан **рабочий HTML-прототип** сайта бронирования номеров (4 экрана с логикой переходов)
- Спроектированы **REST-методы**, проведен маппинг данных, настроена **интеграция с платёжным сервисом** Райффайзенбанк
- Протестированы **API LLM** (OpenAI, YandexGPT) через Postman
- Разработан **RAG pipeline** с использованием Python
- Созданы **GPTs**, настроены **RAG + GPTs**, применено **Fine Tuning**
- Настроен **AI-агент в n8n** для автоматической обработки входящих данных
- В Python + Visual Studio Code разработано **MVP-приложение** для генерации **UML диаграмм**
